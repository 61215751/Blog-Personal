Conclusiones

¿Cuál es la utilidad de las etiquetas básicas?

Las etiquetas básicas de HTML (h1,p,ul,img o div) sirven para darle estructura y significado al contenido de una página. Cada etiqueta le indica al navegador qué tipo de contenido está mostrando: un título, un párrafo, una imagen o una lista, entre otros, lo que permite organizar la información de forma ordenada y accesible.

¿Cuál es la funcionalidad de los estilos CSS?

CSS permite separar el contenido (HTML) de la presentación visual. Con propiedades como color, background-color, border-color o background-image se puede controlar colores, tamaños, espaciados y disposición de los elementos, logrando que una misma estructura HTML se vea de formas muy distintas según el diseño que se le aplique.

En esta práctica utilicé con mayor frecuencia la etiqueta (div), ya que me permitió agrupar secciones de contenido (encabezado, tarjetas del cuerpo y footer) para poder aplicarles estilos de forma independiente con CSS.
